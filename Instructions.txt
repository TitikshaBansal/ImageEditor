# Console-Based Image Editor: User Guide
## Overview
This is a console-based image editor built using C++ and OpenCV. The program allows users to perform various image processing tasks such as applying filters, adjusting colors, cropping, resizing, and saving images via the command-line interface. Follow these steps to get started:

## Prerequisites
1. C++ Compiler: Ensure you have a C++ compiler installed on your system (e.g., g++).
2. OpenCV library installed (version 4.0 or higher)

## Compiling the Code
To compile the code, open a terminal or command prompt. Navigate to the directory containing the source files and run the following command:
``` sh
g++ -o ImageEditor main.cpp image_processing.cpp utilities.cpp `pkg-config --cflags --libs opencv4`
```
This will create an executable file named ImageEditor.

## Running the Program
To run the program, use the following command:
``` sh
./ImageEditor input_image.jpg
```
Replace input_image.jpg with the path to your image file.

## Using the Image Editor
### Main Menu
Upon running the program, you will be presented with a main menu with the following options:
1. Load Image
The program will prompt you to enter the path to an image file (e.g., path/to/your/image.jpg).  
The loaded image will be displayed in the console.  
``` arduino
Enter the path to your image:
path/to/your/image.jpg
```
2. Apply Filters to Image
You can apply different filters to the loaded image. Choose from the following options:
- Gray Scale: Converts the image to grayscale.
- Blur: Applies a Gaussian blur to the image. You will be prompted to enter an odd value for the kernel size (e.g., 3, 5, 7).
- Sharpen: Sharpens the image. You will be prompted to enter a sharpening factor between 0.0 and 1.0.
Follow the on-screen instructions for each filter.

3. Adjust Color of Image
You can adjust the color properties of the image. Choose from the following options:
- Modify Color Palette: Adjusts the image colors based on user-defined RGB values (each value between 0 and 255).
- Adjust Brightness: Adjusts the brightness of the image. You will be prompted to enter an alpha value (1.0-3.0) and a beta value (0-100).
- Enhance Contrast: Adjusts the contrast of the image. You will be prompted to enter an alpha value (1.0-3.0).

4. Crop Image
You can crop the image by specifying the region of interest (ROI). Enter the starting X and Y coordinates, width, and height of the ROI:

``` mathematica
Enter the starting X-coordinate: 50
Enter the starting Y-coordinate: 50
Enter the width of the ROI: 100
Enter the height of the ROI: 100
```
The cropped image will be displayed.

5. Resize Image
You can resize the image by specifying the new width and height:
``` arduino
Enter the new width: 200
Enter the new height: 200
```
The resized image will be displayed.

6. Save Image
You can save the edited image by specifying the file path and name (e.g., path/to/save/MyImage.jpg):

```vbnet
Enter the location where you want your edited image to be saved:
path/to/save/MyImage.jpg
```
The image will be saved, and the modified version will be displayed.

7. EXIT
Choose this option to exit the program.

## Notes
- Ensure that the input values are within the specified range and valid for the operation.  
- The program will display the modified image in a window after each operation. Close the window to continue with the next operation.
- The program will notify you if any errors occur during image loading or saving.

## Troubleshooting
If you encounter any issues, ensure that OpenCV is correctly installed and that the image file path is valid.
