## How to Contribute

## Reporting Bugs

If you find a bug, please report it by [creating an issue](https://github.com/TitikshaBansal/ImageEditor/issues) in our GitHub repository. Please include:

- A clear and descriptive title.
- A detailed description of the bug, how to reproduce it, and what you expected to happen.
- Any relevant screenshots, code snippets, or error messages.

## Suggesting Enhancements

We welcome suggestions to make ImageEditor better! To suggest an enhancement:

- Open an issue on GitHub with a clear and descriptive title.
- Provide a detailed description of the enhancement, why it would be useful, and how you envision it working.

## Your First Code Contribution

If you're new to contributing to open source projects, here are some ways you can start contributing to ImageEditor:

- Fixing typos or improving documentation.
- Addressing open issues.
- Adding new features or improving existing ones.

Please check our list of [good first issues](https://github.com/TitikshaBansal/ImageEditor/issues?q=is%3Aissue+is%3Aopen+label%3A"good+first+issue") for ideas.

## Pull Requests

When you're ready to contribute code, please follow these steps:

1. Fork the repository to your GitHub account.
2. Clone the forked repository to your local machine:
   ```sh
   git clone https://github.com/TitikshaBansal/ImageEditor.git
   ```
3. Create a new branch for your changes:
```sh
git checkout -b your-feature-branch
```
4. Make your changes and commit them with clear and descriptive commit messages.
5. Push your changes to your forked repository:
```sh
git push origin your-feature-branch
```
6. Open a pull request in the main repository:
- Go to the original repository and click on the "Pull Requests" tab.
- Click on the "New Pull Request" button and follow the prompts to create your pull request.

## Code Style

To maintain a consistent codebase, please adhere to the following coding standards:
- Use appropriate naming conventions for variables, functions, and classes.
- Ensure your code is well-commented and easy to understand.
- Follow the formatting guidelines for C++ (e.g., proper indentation, spacing).
